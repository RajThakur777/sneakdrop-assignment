# Notes

## How to run

1. Install Node.js (v14 or higher is recommended).
2. Run `npm install` in the project root to install the dependencies (`express`, `uuid`).
3. Run `npm start` (or `node backend/server.js`) to start the backend server.
4. The server will start on port 3000.
5. Open your browser and navigate to `http://localhost:3000/` to test the UI flow.

## Requirements

- Node.js (v14+)
- npm (Node Package Manager)

## Testing

To run the automated tests, use the following commands:
1. Run `npm install` (this will also install `jest` and `supertest` for testing).
2. Run `npm test` to execute the test cases.
